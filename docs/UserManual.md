# 集團知識庫系統操作使用手冊

本手冊旨在引導集團內所有同仁、主管與管理員，熟悉集團知識庫（GigaSolar Knowledge Base）的各項操作流程。系統提供跨公司及跨部門的知識檢索、文章共筆、附件版本控管與精細的權限管理機制。

## 一、 手冊概述與登入指引
「集團知識庫」是一套專為 GigaSolar 集團設計的內部文件、知識與技術手冊管理系統，為同仁在跨部門、跨專案協作中提供堅實的支援。系統具備細緻的人員權限配置與多公司/部門層次切換功能。

### 1.1 系統認證與登入流程
系統已與集團的 **BPM（業務流程管理系統）** 帳號進行深度整合。為了保障資訊安全，系統本身**不另行儲存或維護使用者的密碼**。請使用您既有的 開機 帳號進行驗證登入。

> **ℹ️ 認證儲存規範：**
> 登入取得的憑證（Token）將安全地儲存於瀏覽器的 `sessionStorage` 中。當您**關閉該瀏覽器分頁（Tab）**或**另開新分頁**時，該 Token 即失效，系統會自動將您導回登入頁，此為保障商業機密的安全防護設計。

### 1.2 登入頁按鈕與欄位說明

| 介面元素 | 操作類型 | 功能與運作說明 |
| --- | --- | --- |
| **員工工號** 欄位 | 文字輸入框 (User) | 請輸入您的集團員工工號（例如：S112009）。此欄位為必填。 |
| **密碼** 欄位 | 密碼輸入框 (Lock) | 請輸入您的 開機 登入密碼。本欄位支援 `顯示/隱藏密碼` 切換。此欄位為必填。 |
| `登入` | 主要動作按鈕 | 點擊或按鍵盤 Enter 後，系統會向後端傳送認證請求。登入成功後將導向知識庫首頁；失敗時會彈出「登入失敗，請確認工號與密碼」的提示。 |

## 三、 首頁功能說明
首頁是同仁每天的工作大廳，提供了全系統的**快速檢索引擎**與**個人通知中心**。

### 3.1 知識檢索與標籤篩選
檢索引擎採用即時模糊搜尋技術，可以同時對知識庫內的所有「文章標題/內文」與「附件檔名/說明」進行全方位檢索。

| 介面按鈕 / 元素 | 操作類型 | 功能與運作說明 |
| --- | --- | --- |
| **搜尋輸入框** | 關鍵字輸入 (Search) | 輸入欲查詢之關鍵字。系統會在您停止輸入後的 300 毫秒後，自動觸發即時搜尋。 |
| `重置搜尋` | 動作按鈕 | 點擊立即清空搜尋輸入框中的關鍵字，並取消所有勾選的篩選標籤，恢復首頁預設展示狀態。 |
| **標籤篩選** 區域 (Tags) | 多選按鈕 (Check Tag) | 展示目前範圍下的熱門或常用標籤。點擊標籤進行「與 (AND)」多重過濾。<br>在**公開模式下點選標籤，會自動累加該標籤的熱度點擊數**。 |
| **搜尋結果列表項目** | 導覽連結卡片 | 搜尋結果會依最後更新時間排序，並以標籤明確區分：<br>- `文章`：點擊即導向文章詳細閱讀頁。<br>- `附件`：點擊即導向附件詳細與下載頁。<br>※ 運作機制：若搜尋結果屬於其他授權部門，系統會自動在背景切換目錄樹至該部門，以防連結失效。 |

### 3.2 通知中心管理
通知中心為使用者集中處理留言提及 (@mention) 的地方，確保工作指令與問題回饋不漏接。

| 介面按鈕 / 元素 | 操作類型 | 功能與運作說明 |
| --- | --- | --- |
| **未讀通知卡片項目** | 導覽卡片 | 顯示提及您的文章名稱、提及者名稱、留言內容預覽以及時間。點擊卡片將自動跳轉至該文章的對應留言位置。 |
| `已查看` (通知卡片內) | 動作按鈕 | 點擊將該通知標記為「已讀」，此通知會隨即移入右側「已讀通知」列表中。 |
| **已讀通知列表** | 歷史展示區 | 展示近 30 天內已被讀取的歷史提及通知，作為工作紀錄備查。 |

## 四、 目錄樹架構與管理
目錄樹 (DirectoryTree) 是系統管理所有文件分類的靈魂，左側面板以階層結構呈現：**公司 ➔ 部門 ➔ 目錄 ➔ 文章/附件**。

### 4.1 目錄樹權限防護
系統對目錄樹上的每一個檔案項目都設有嚴密的安全防護。如果某個檔案項目受限於職級或特定部門：
*   無存取權限的檔案在目錄樹中會呈現**灰色文字**，且右方會標示 `🔒 無存取權限` 圖示。
*   此時點擊該檔案，系統會發出警告「**目前無存取該文件的權限**」並拒絕導航，防止內部資料外洩。

### 4.2 主管專屬：目錄樹管理與排序操作
僅有 `主管 (MANAGER)` 與 `管理員 (ADMIN)` 可以對目錄進行結構與順序的調整。

> **⚠️ 目錄拖曳排序規則：**
> 系統目錄樹支援**滑鼠拖曳重排（Drag and Drop）**。您只能將目錄拖曳至「其他目錄」或「部門節點」內部作為子目錄，或是同層目錄之間前後排序。系統嚴格限制並禁止將目錄拖曳至「公司」、「文章」、「附件」或「垃圾桶」周圍。

| 介面按鈕 / 元素 | 操作類型 | 功能與運作說明 |
| --- | --- | --- |
| `🔄` (目錄樹頂部) | 重新整理按鈕 | 點擊會向伺服器重新獲取最新的目錄樹結構與檔案狀態，同步最新協作成果。 |
| `➕` (目錄樹頂部) | 主管專用按鈕 | 僅限主管顯示。點擊在當前部門的最上層建立一個全新的「一級主目錄」。 |
| `⋯` (目錄節點移入時) | 下拉功能按鈕 (More) | 僅限主管顯示。滑鼠移入目錄節點時浮現，點擊會展開管理子選單： |
| ↳ `➕ 新增子目錄` | 選單動作 | 在此目錄下方新建下一層的子目錄。 |
| ↳ `📝 重新命名` | 選單動作 | 彈出文字輸入框，直接修改該目錄的名稱。 |
| ↳ `🗑️ 移除目錄` | 選單動作 | 刪除該分類目錄。<br>**安全機制：**若該目錄中仍然含有檔案或子目錄，系統會警告「目錄內還有檔案或子目錄，無法直接移除！」，必須先移空內容方可刪除。 |

## 五、 知識庫文章管理
文章是系統核心的知識載體，提供多人線上即時協作防鎖機制與高階 Markdown 編輯器。

### 5.1 閱讀/瀏覽模式 (View Mode)
提供乾淨舒適的排版，同仁可在下方的**屬性描述列表**中查看該文章的標籤、關聯之附件、設定權限，以及該文章目前的 **RAG 同步狀態**（顯示 AI 是否已將此文章處理為可問答的知識，各狀態意義詳見第九章 9.4 節）。

| 介面按鈕 / 元素 | 操作類型 | 功能與運作說明 |
| --- | --- | --- |
| `🪄 AI 輔助` (標題列左側) | 側邊面板開啟按鈕 | 點擊從右側拉出「AI 輔助」面板，於瀏覽模式下預設為 **AI 問答**分頁，可針對本篇文章內容直接提問。功能與第九章之 AI 智慧問答完全相同，僅差在已自動帶入本文內容作為上下文。 |
| `評論` (底端/右上方) | 抽屜面板切換按鈕 | 點擊從右側拉出「文章評論抽屜」。同仁可在此留言討論。<br>**@提及功能：**在留言框中輸入 `@` 會自動彈出目前部門的同仁名單（支援中文與拼音搜尋），點選指定同仁會發送 in-app 提及通知。 |
| `修改紀錄 v[數字]` | 抽屜面板切換按鈕 | 點擊從右側展開「版本歷史與紀錄面板」。展示文章從建立至今的所有修改記錄。<br>**版本追溯：**點擊歷史版本中的項目，可回溯閱讀舊版本的文章內容。 |
| `返回最新版本` | 動作按鈕 | 僅在閱讀歷史舊版本文章時出現，點擊快速切換回最新的文章版本。 |
| `編輯` | 模式切換按鈕 | 若您擁有本文章的修改權限，點擊會使文章進入**編輯模式**並載入 Vditor 編輯器。<br>**多人編輯防護：**若此時有其他同仁正在編輯，系統會顯示 `🔄 [姓名] 編輯中` 狀態，並鎖定按鈕防止內容覆蓋衝突。 |
| **描述列表中的附件連結** | 超連結跳轉 | 若文章已關聯附件，點擊可直接導航跳轉至對應的附件管理頁面。 |

### 5.2 編輯與建立模式 (Edit / Create Mode)
在此模式下，您可以修改文章的基本屬性、安全權限，並透過 Markdown 編輯器進行內容撰寫。

| 介面按鈕 / 元素 | 操作類型 | 功能與運作說明 |
| --- | --- | --- |
| `🪄 AI 輔助` (標題列左側) | 側邊面板開啟按鈕 | 在**建立文章**模式下自動切至「產生文章」分頁，可輸入提示詞或上傳 Word/PDF（≤5MB）請 AI 產生 Markdown 草稿；在**編輯既有文章**模式下自動切至「校正文章」分頁，點擊送出即由 AI 校正目前編輯中的內容。兩者皆可點擊 AI 回覆下方的 `一鍵貼入編輯器` 按鈕，經二次確認後覆蓋目前內容（詳見第九章 9.2 節）。 |
| `⬅️` **退回查看** | 模式切換按鈕 | 點擊捨棄當前未儲存的變更，退回瀏覽模式。 |
| **文章標題** 輸入框 | 文字輸入框 | 輸入或修改文章標題。此標題將做為目錄樹上顯示之名稱。 |
| `選擇目錄` | 彈出 Dialog 選取框 | 文章在目錄樹中**支援多重分類歸屬**。點擊開啟 Dialog 勾選本文章存放的目錄節點（可多選）。 |
| `關聯文件` | 彈出 Dialog 選取表單 | 點擊開啟 Dialog，在清單中勾選欲與本文章產生強烈關聯之附件檔案。 |
| **標籤** 下拉選單 | 多選與建立選單 | 可選取部門標籤。本選單支援**直接輸入文字後按 Enter** 以快速建立並綁定全新標籤。 |
| **是否公開** 單選鈕 | 單選組 (Radio) | - **全集團公開：**任何跨部門、跨公司的同仁在切為「公開文件」時皆可搜尋與閱讀。<br>- **部門私有：**僅限本部門成員或指定人員方可閱讀。 |
| `指定可編輯同仁` | 彈出 Dialog 勾選框 | 預設情況下，文章僅能由「建立者」、「主管」與「管理員」修改。點擊可授權勾選部門內其他同仁共同編輯此文章。 |
| **查看權限 – 指定人員** | 下拉多選選單 | 僅在「部門私有」時生效。預設空白代表部門全員可看，若選取了特定同仁，則該文章將轉為**極機密限制級別**，僅名單內同仁可閱讀。 |
| **查看職級門檻** 下拉選單 | 下拉單選選單 | 設定查看本文章所需的最低級職：<br>- **一般人員（全員可見）**：級職 threshold 設為 10。<br>- **課級以上**：級職 threshold 設為 7。<br>- **理級以上**：級職 threshold 設為 6。<br>- **處級以上**：級職 threshold 設為 4。 |
| **文件上架** 單選鈕 | 單選組 (Radio) | - **上架：**正常於系統與目錄樹中展示。<br>- **下架：**點選下架會**自動清空原目錄歸屬，並將文章移入「垃圾桶節點」中**，停止前台檢索與呈現。 |

| **Vditor Markdown 編輯器** | 富文字/Markdown 區 | 支援即時預覽（IR 模式）、大綱清單、代碼高亮。<br>**圖片拖曳 Hook：**支援直接拖曳圖片或複製截圖貼上至編輯器中，系統會自動呼叫後端 API 完成上傳並生成網頁圖片代碼。 |
| `儲存` | 主要儲存動作按鈕 | 點擊進行必填欄位檢查，儲存變更，建立全新版本，並刷新側邊目錄樹，隨後退回瀏覽模式。 |
| `建立` (僅新建文章時) | 主要建立動作按鈕 | 點擊將新文章儲存至伺服器，並導航至新建文章之詳細閱讀頁面。 |

## 六、 知識庫附件管理
附件管理模組專門用來存放非 Markdown 格式的實體檔案（如 PDF 操作手冊、Excel 數據表或 Word 法規文件），並對檔案提供嚴格的版本回溯控管。

### 6.1 閱讀與下載模式 (View & Download)
與文章界面類似，底端設有專屬的「附件說明」展示區，以及最重要的「檔案清單與下載控制」。

| 介面按鈕 / 元素 | 操作類型 | 功能與運作說明 |
| --- | --- | --- |
| **關聯文章連結** (屬性表內) | 超連結跳轉 | 如果此附件有關聯文章，點擊可直接跳轉至文章詳細閱讀頁面。 |

## 九、 AI 智慧輔助功能說明
為提升集團同仁的文件撰寫效率與知識檢索體驗，系統已正式啟用 AI 智慧輔助模組，串接 **AiRAG 知識庫檢索服務**（模型標示為 `qwen3.6:35b`），提供智慧問答、寫作輔助與內容校正功能。

> **ℹ️ 前置條件：**
> AI 功能需由管理員於「管理員設定 → API Key 設定」頁籤完成 AiRAG 服務金鑰與知識庫 ID 設定（詳見第八章）才能正常運作。若管理員尚未設定或金鑰失效，AI 問答時會顯示錯誤訊息，請洽詢資訊人員。

### 9.1 AI 智慧問答
系統提供兩種進入 AI 問答的方式，兩者底層邏輯完全共用：

| 進入方式 | 對應介面位置 | 說明 |
| --- | --- | --- |
| **AI 問答頁面** | 最左側主選單 `💬 AI問答` | 獨立全頁面，對話內容會保留在瀏覽期間的全域狀態中，切換其他頁面後再回來不會遺失。公開與部門文件模式下皆可使用。 |
| **AI 輔助面板** | 文章瀏覽頁標題列 `🪄 AI 輔助` | 側邊彈出面板，會自動帶入目前瀏覽文章的內容作為問答上下文（可用勾選框開關是否包含）。關閉面板後對話不會保留。 |

**問答輸入方式：**

| 操作 | 功能與運作說明 |
| --- | --- |
| 直接輸入問題並送出 | 若未指定任何文章／附件，系統會呼叫 AiRAG 進行一般知識庫語意問答，並在回覆下方列出**引用來源**（顯示來源檔名、段落序號、與問題的相似度分數，以及該段落是否「已採納」進入 AI 回答的上下文）。 |
| 輸入 `#` + 關鍵字 | 彈出可指定文章的下拉清單（僅列出目前有權限檢視、未下架的文章），選定後 AI 會針對該文章內容回答，不再走一般知識庫檢索。 |
| 從左側目錄樹拖曳文章或附件節點 | 拖入 AI 問答頁面的訊息區即可直接引用。拖曳**附件**時會彈出「選擇要引用的檔案」對話框，僅 PDF／Word 檔案可勾選（其餘格式會標示「AI 暫不支援此格式」），確認後系統會擷取檔案文字內容。已引用文章與檔案的合計文字量上限為 **50,000 字**，超過上限會提示縮減引用範圍。 |
| 快速指令按鈕（`簡易摘要` / `詳細摘要` / `步驟詳解`） | 已指定文章或引用檔案時顯示，點擊即送出對應的預設提示詞，無需自行輸入問題。 |

**回覆內容說明：**

| 元素 | 說明 |
| --- | --- |
| 💡 **思考過程**（可摺疊） | 若模型有回傳推理內容，會以摺疊區塊顯示「思考中...」動畫，串流結束後可點擊展開查看完整思考過程。 |
| **參考來源** | 條列 AI 本次回答所依據的知識庫段落，點擊可展開查看該段落原文。 |
| **AI 建議關鍵字** | 系統會從 AI 回覆中的 `**粗體字**` 擷取候選關鍵字，點擊即可一鍵將該詞加入指定文章（或當前瀏覽文章）的標籤，已加入者會顯示打勾圖示。 |
| `🔄 新對話` | 清空目前對話紀錄與已引用內容，重新開始。 |

### 9.2 AI 寫作輔助（產生文章／校正文章）
在文章的**建立**與**編輯**模式下，點擊標題列的 `🪄 AI 輔助` 會自動切換到對應的輔助分頁：

| 模式 | 觸發時機 | 功能說明 |
| --- | --- | --- |
| **產生文章** | 建立文章（`mode=create`） | 可輸入提示詞（例如「撰寫一篇關於 Redis 快取策略的技術文章」），或上傳 `.doc / .docx / .pdf` 檔案（單檔上限 5MB），由 AI 產生 Markdown 格式的文章草稿。 |
| **校正文章** | 編輯既有文章 | 點擊送出後，AI 會直接以目前編輯器中的文章內容進行錯字校正、語句修飾與格式調整，無需額外輸入。 |

兩種模式產生內容後，皆會在回覆下方出現 `一鍵貼入編輯器` 按鈕。點擊後會彈出確認視窗提示「這將覆蓋現有的文章內容」，確認後才會將 AI 產生內容寫入 Vditor 編輯器，避免誤觸覆蓋既有內容。

### 9.3 進階檢索設定
AI 問答頁面與面板下方皆提供兩組拉桿，供同仁依情境調整檢索行為（面板需切換至 AI 問答分頁才會顯示）：

| 拉桿 | 範圍 | 說明 |
| --- | --- | --- |
| **思考模式** | 快速／嚴謹（2 級） | 快速：使用 `KB_hybrid` 檢索，回應速度較快；嚴謹：使用 `KB_semantic_hybrid` 檢索，品質較佳但速度較慢。 |
| **資料撈取** | 寬鬆～嚴謹（1～10 級，共 10 級，各級皆有中文標籤如「極寬鬆」「中等平衡」「極嚴謹」） | 寬鬆：AI 取得的候選資料較多、思考較久，適合模糊或探索性問題；嚴謹：精準篩選相似度較高的資料，適合明確、聚焦的問題。 |

### 9.4 RAG 同步狀態說明
文章與附件（PDF／Word 檔案）詳細頁的屬性描述列表中，皆會顯示該內容目前的「RAG 同步狀態」，代表 AI 是否已能在問答中檢索到此內容：

| 狀態標籤 | 代表意義 |
| --- | --- |
| **AI 待處理** | AI 尚未處理此資料，暫時無法被問答檢索到。 |
| **AI 待更新** | 內容已被修改，等待系統排程或管理員手動觸發重新處理。 |
| **AI 處理中** | AI 正在將此資料切分、產生向量並寫入知識庫。 |
| **AI 已就緒** | AI 已處理完成，可於問答中被檢索與引用。 |
| **AI 處理失敗** | 向量處理發生錯誤，請洽詢資訊人員；管理員可於後台「RAG 同步比對」頁籤查看錯誤訊息並手動重新執行。 |
| **已下架 (已刪除向量)** | 內容已下架，對應的 AI 檢索向量資料已一併刪除。 |
| **已下架 (移除問答)** | 內容已下架，並已從 AI 問答資料中完全移除。 |
